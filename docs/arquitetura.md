# Arquitetura do Ambiente de Testes

## 1. Sistema operacional

Kali Linux, utilizado como plataforma para execução das ferramentas de auditoria.

## 2. Aplicação-alvo

DVWA (Damn Vulnerable Web Application), instalada em ambiente controlado e isolado.

## 3. Ferramentas

- Medusa: ferramenta de auditoria de autenticação.
- Nmap: ferramenta de descoberta de hosts e serviços.
- Kali Linux: sistema operacional do laboratório.

## 4. Ambiente de execução

O laboratório será executado em máquina virtual, com comunicação restrita entre os componentes.

## 5. Segurança

Todos os testes serão realizados exclusivamente em sistemas próprios ou expressamente autorizados.

O ambiente não deverá ficar exposto à internet.
